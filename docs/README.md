# Документация Forte Cashier Guard

## Для жюри

- [Обзор решения](../README.md): доступ, архитектура, модель, результаты и локальный запуск.
- [Инструкция для жюри](JURY_INSTRUCTIONS.md): загрузка видео, авторизация и точная схема API.
- [Модель и оценка](MODEL.md): методика, метрики и условия измерений скорости.
- [Модели и лицензии](MODELS_LICENSES.md): используемые компоненты и эксперименты команды.

## Для развёртывания и сопровождения

- [Эксплуатация](OPERATIONS.md): запуск, перенос хоста, конфигурация и диагностика.
- [Модельный контракт](MODEL_INTEGRATION.md): полный комплект весов, адаптер, потоки и инструменты.
- [Состав интегрированной версии](STATUS.md): архитектура и проверка доступности.

состоянием интегрированного релиза.
