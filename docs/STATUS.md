# Integrated release overview

The repository contains the integrated cashier-video analysis service: the Russian React
interface, FastAPI API, PostgreSQL persistence, the local computer-vision pipeline and
regulatory citations. Model weights are distributed separately from Git.

## Architecture

- One uvicorn process serves the UI from `static/` and both API route families.
- Jury clients use `/api/v1/analyze` and `/api/v1/jobs/{job_id}` with `X-API-Key`.
- The browser uses same-origin `/ui/api/*` routes without embedding the jury key.
- A thread executor runs `model_service.py`, backed by `ml/`: RT-DETRv2 ONNX detection,
  ByteTrack tracking, DINOv2-small crop features, logistic heads, timelines and calibrated rules.
- Citations come from `rules/rules_db.json`. They are not generated by a language model.
- PostgreSQL stores job states, results and JPEG evidence. Uploaded videos are temporary.
- The runtime is CPU-only. Bundled assets and weights support offline inference;
  public access through ngrok requires an internet connection.

## Runtime configuration

Compose defaults to `WORKERS=1`, `FORTE_THREADS=6`, `JOB_TIMEOUT_SEC=270` and
`EVIDENCE_FRAMES=3`. Keep one API container/process per database and upload volume.
The adapter shares an Analyzer and changes its detector stride per request; increasing
workers requires a separate concurrency review, not just a speed benchmark.

`models/` must contain the complete trained detector, encoder, classifiers and calibration
parameters. An empty directory does not start the integrated model. Source files and a
weights bundle must be the same version. The bundled rule database is under `rules/`;
`data/` is an optional mount for additional local sources.

## Evidence and evaluation

- The infrastructure-stage report records 119 passing tests, including real HTTP and
  restart persistence checks: [historical verification](HARDENING_VERIFICATION.md).
- Model quality and Docker/Mac timing measurements are documented in [MODEL.md](MODEL.md).
  They are separate from application regression tests.
- A read-only public check on 18 October 2026 returned UI HTTP 200 and health HTTP 200
  with `model_loaded=true`, `demo_mode=false`, `workers=1`. An unauthenticated jury request
  returned HTTP 401. This is an availability snapshot, not a video evaluation or a
  verification of the API key entered in the submission form.
