# Forte Cashier Guard — фронтенд (Datathon 26)

Веб-интерфейс AI-сервиса контроля кассовой дисциплины. Стек: **React 18 + TypeScript + Vite + чистый CSS**.
Шрифты подключены локально через `@fontsource` — интернет для работы UI не нужен.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev          # http://localhost:5173 (лучше открывать в Chrome или Safari)
npm run build        # production-сборка в dist/
npm run build:single # один HTML-файл в dist-single/
```

## Оформление

Страница сервиса в фирменном стиле Forte (палитра и пропорции сняты со скриншотов forte.kz): лаконичная шапка (логотип,
название сервиса, переключатель «Режим: заглушка API»), баннер с кнопкой загрузки и индикатором этапов, серая рабочая область
с белыми карточками, блок «Безопасность и доверие», градиентный футер. Видеомонитор сохранил элементы VMS (OSD-метки,
маркеры событий на таймлайне, покадровый шаг). Логотип и знак «F» — из файла ТЗ (`src/assets`). Шрифт — Golos Text; точный
шрифт сайта подключается заменой `--sans` в `src/styles/app.css`.

## Что умеет

1. **Загрузка .mov**: кнопка в баннере, drag & drop или выбор файла; проверка формата (только `.mov`) и размера.
2. **Прогресс**: загрузка (реальный % по байтам) → анализ (таймер + лимит 5 минут из ТЗ) → результат.
3. **Окно результата**: `job_id`, `status`, `verdict`, вердикт-баннер, список событий. У каждого события: тип и описание,
   таймкод (клик — перемотка видео), правило и нормативный источник, 1–3 кадра-доказательства (клик — увеличение, стрелки ← →).
   Вкладка **JSON** — «сырой» ответ API.
4. **Видеомонитор**: плеер с отметками событий, покадровый шаг, подсветка момента события.
5. Состояния: «нарушений нет», «ошибка обработки», тайм-аут 5 минут, повтор.

## Сейчас работает на заглушке

Пока API не готов, UI работает на `src/lib/mockApi.ts` (переключатель — кнопка «Режим: заглушка API» в шапке):

- загрузка файла настоящая (файл читается кусками, прогресс реальный);
- `job_id` случайный; через ~7 с приходит результат;
- таймкоды считаются от реальной длительности вашего видео, кадры вырезаются из вашего видео
  (если браузер не декодирует кодек — длительность берётся из атома `mvhd`, а кадры рисуются заглушками);
- **типы нарушений, описания и нормативные ссылки — ПЛЕЙСХОЛДЕРЫ**, помечены в UI. Конкретные пункты НПА в заглушку
  намеренно не вписаны (критерий 4 — «никаких выдуманных ссылок»): подставляйте только проверенные на adilet.zan.kz;
- в настройках можно выбрать сценарий заглушки: «Нарушения найдены» / «Нарушений нет» / «Ошибка обработки».

## Подключение реального API

1. `cp .env.example .env`, поставьте `VITE_USE_MOCK=false` (или переключите режим в шапке на «Реальный API»).
2. В dev-режиме `/api/*` проксируется на `API_PROXY_TARGET` (по умолчанию `http://localhost:8000`).
   В проде раздавайте фронт с того же origin, что и API, либо задайте `VITE_API_BASE`.
3. Если UI должен ходить в защищённый API напрямую — `VITE_API_KEY` (уйдёт в `X-API-Key`).
   Значения `VITE_*` попадают в браузерный бандл, поэтому для публичного URL лучше пускать UI через свой бэкенд-прокси.

Контракт (раздел 10 ТЗ) — `src/lib/httpApi.ts`:

| Метод | Путь | Что делает фронт |
|---|---|---|
| POST | `/api/v1/analyze` | multipart, поле `file` (.mov) → ждёт `{ "job_id": "..." }` |
| GET | `/api/v1/jobs/{job_id}` | опрос каждые 1.5 с: `processing` — ждём, `done` — показываем, `failed` — ошибка |

Типы ответа — `src/lib/types.ts`. Одно необязательное дополнение к схеме ТЗ: поле `rule` (`{ document, clause, url? }`)
у каждого нарушения — ТЗ (раздел 4, п. 7) требует показывать правило и источник, а в JSON-схеме API для него поля нет.
Если бэкенд его не отдаёт — блок скрыт.

## Структура

```
src/
  App.tsx                 каркас страницы, drag&drop на уровне окна, валидация
  hooks/useAnalysis.ts    автомат: idle → uploading → processing → done | failed
  lib/                    types, config, httpApi (реальный), mockApi (заглушка), frames, validate, format
  components/             TopBar, Hero, UploadZone, VideoMonitor, ResultPanel, FrameLightbox, InfoCards, SiteFooter, Icon
  styles/app.css          токены и все стили
```

## Ограничения

- Предпросмотр .mov зависит от кодека в браузере (Chrome/Safari/Edge воспроизводят H.264-.mov). На загрузку и анализ это не влияет.
- Лица не распознаются (ТЗ, FAQ №29) — интерфейс только показывает кадры, пришедшие от бэкенда.
